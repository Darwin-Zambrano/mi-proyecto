# mi-proyecto
Proyecto inicial Front-End y Back-End con Node.js

## Descripción
Este proyecto demuestra la conexión entre una interfaz HTML/CSS/JS y un servidor Node.js con Express.

## Instalación
1. Abrir la carpeta `backend` en Visual Studio Code.
2. Ejecutar los comandos:
npm install
node server.js
3. Abrir el navegador en `http://localhost:3000`.

## API
- **GET** `/api/saludo` → retorna un mensaje en formato JSON.
